# nardo-stack

The open-source stack behind the build: tools, projects, and builders worth
studying when making practical AI workflows.

This is a public reading list, not a mirror of a private system. It has no
runtime, no credentials, no deploy scripts, and no private workflow state.

## Browser Automation

- **[daijro/camoufox](https://github.com/daijro/camoufox)** - Firefox fork with fingerprint-spoofing features for browser automation research.
- **[Kaliiiiiiiiii-Vinyzu/patchright-python](https://github.com/Kaliiiiiiiiii-Vinyzu/patchright-python)** - Playwright-oriented browser automation toolkit.

## Claude Code

- **[rtk-ai/rtk](https://github.com/rtk-ai/rtk)** - CLI token compression tool for packing codebases into LLM-ready context.
- **[obra/superpowers](https://github.com/obra/superpowers)** - Claude Code skills reference and design inspiration.
- **[muratcankoylan/agent-skills-for-context-engineering](https://github.com/muratcankoylan/agent-skills-for-context-engineering)** - Skills and context-engineering patterns.

## Web Scraping & Social Media

- **[mendableai/firecrawl](https://github.com/mendableai/firecrawl)** - LLM-ready web scraping API.
- **[xcrawl.com](https://xcrawl.com)** - Web scraping API with multi-engine search support.
- **[d60/twikit](https://github.com/d60/twikit)** - X/Twitter client library without the official API.
- **[NanmiCoder/MediaCrawler](https://github.com/NanmiCoder/MediaCrawler)** - Multi-platform Chinese social media crawler reference.
- **[huccihuang/bilibili-mcp-server](https://github.com/huccihuang/bilibili-mcp-server)** - Bilibili MCP server for video and content access.

## RSS & Feeds

- **[DIYgod/RSSHub](https://github.com/DIYgod/RSSHub)** - Everything-to-RSS bridge for many sites and platforms.

## Voice & Audio

- **[SYSTRAN/faster-whisper](https://github.com/SYSTRAN/faster-whisper)** - CTranslate2 implementation of Whisper for speech recognition.
- **[jaredks/rumps](https://github.com/jaredks/rumps)** - macOS menu bar app toolkit.
- **[RVC-Boss/GPT-SoVITS](https://github.com/RVC-Boss/GPT-SoVITS)** - Voice synthesis and voice cloning research project.
- **[FunAudioLLM/CosyVoice](https://github.com/FunAudioLLM/CosyVoice)** - Voice synthesis model from FunAudioLLM.

## Face Analysis & 3D

- **[google/mediapipe](https://github.com/google/mediapipe)** - Face Mesh and real-time perception models.
- **[mrdoob/three.js](https://github.com/mrdoob/three.js)** - 3D rendering library for browser-based visual interfaces.
- **[pichiliani/ModelsOBJ](https://github.com/pichiliani/ModelsOBJ)** - Public collection of OBJ model examples.
- **[cleardusk/3DDFA_V2](https://github.com/cleardusk/3DDFA_V2)** - 3D face reconstruction with dense alignment.

## Knowledge Graphs

- **[safishamsi/graphify](https://github.com/safishamsi/graphify)** - Turn folders of code, docs, or papers into navigable knowledge graphs.

## Media & Video

- **[yt-dlp/yt-dlp](https://github.com/yt-dlp/yt-dlp)** - Video and audio downloading toolkit.
- **[FFmpeg/FFmpeg](https://github.com/FFmpeg/FFmpeg)** - Audio and video processing backbone.
- **[charmbracelet/vhs](https://github.com/charmbracelet/vhs)** - Terminal recording to GIF/MP4.

## Image Generation

- **[comfyanonymous/ComfyUI](https://github.com/comfyanonymous/ComfyUI)** - Node-based Stable Diffusion UI.

## Code & Security

- **[ast-grep/ast-grep](https://github.com/ast-grep/ast-grep)** - Structural code search and linting with AST patterns.
- **[gitleaks/gitleaks](https://github.com/gitleaks/gitleaks)** - Secret scanning for git repositories.
- **[tesseract-ocr/tesseract](https://github.com/tesseract-ocr/tesseract)** - OCR engine for extracting text from images.
- **[yamadashy/repomix](https://github.com/yamadashy/repomix)** - Pack repositories into LLM-ready files.

## TUI & Desktop

- **[Textualize/textual](https://github.com/Textualize/textual)** - Python TUI framework.

## Maintenance

- Motto: The open-source stack behind the build.
- Runtime: none.
- Dependencies: none in this repository.
- Sync posture: manual-release only; this repo should not auto-sync from a private system.
